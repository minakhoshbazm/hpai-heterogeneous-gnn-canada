# Final Technical Experiment Report: Graph-Augmented Tabular Risk Model

## Executive Summary & Final Scientific Classification

We implemented, benchmarked, and evaluated the **Graph-Augmented Tabular Risk Model** family for 1-month-ahead HPAI poultry outbreak prediction across all 5,054 Canadian Census Subdivisions (CSDs) from January 2022 through November 2025.

The core architecture concatenates original 62 CSD-month tabular features $X_{i,t}$ with 64-dimensional spatial node embeddings $z_{i,t}$ generated by a supervised GraphSAGE spatial encoder into an augmented 126-dimensional representation $\tilde{X}_{i,t} = [X_{i,t} \mathbin{\Vert} z_{i,t}]$, which is fed into strong tabular classifiers (LightGBM, XGBoost, PyTorch MLP, Random Forest, Logistic Regression).

To protect against stacking overfitting, training embeddings were generated using **Temporal Out-of-Fold (OOF) Embedding Extraction** across 2022–2023 training data, while validation (2024) and test (2025) embeddings were extracted using a frozen full-train encoder.

### Scientific Classification: **OUTCOME D (STRONG TABULAR MODELS CAPTURE DOMINANT SIGNAL)**

#### Primary Scientific Findings:
1. **Strong Tabular & Standalone Baselines**:
   - **Tabular-Only PyTorch MLP**: AP = **0.0723**, ROC-AUC = **0.9227**, Macro R@50 = **17.36%**.
   - **Tabular-Only XGBoost**: AP = **0.0487**, ROC-AUC = **0.9325**, Macro R@50 = **17.89%**.
   - **Tabular-Only LightGBM**: AP = **0.0447**, ROC-AUC = **0.9341**, Macro R@50 = **18.22%**.
   - **Standalone GraphSAGE GNN** (from previous phase): AP = **0.0903**, ROC-AUC = **0.9109**, Macro R@50 = **20.01%**.

2. **Graph-Augmented Model Performance**:
   - **Graph-Augmented PyTorch MLP**: AP = **0.0675**, ROC-AUC = **0.9194**, Macro R@50 = **15.70%**.
   - **Graph-Augmented XGBoost**: AP = **0.0574**, ROC-AUC = **0.9123**, Macro R@50 = **15.41%**.
   - **Graph-Augmented LightGBM**: AP = **0.0318**, ROC-AUC = **0.9236**, Macro R@50 = **17.53%**.

3. **Topological Controls & Shuffled Realizations**:
   - Graph-Augmented LightGBM with real geographic edges (**0.0318**) marginally outperformed Shuffled-Edge LightGBM (**0.0312**, +0.00025 AP diff, `[+0.0000, +0.0005]`, 98.8% win rate) and Self-Loop LightGBM (**0.0315**, +0.00031 AP diff, `[+0.0001, +0.0006]`, 100% win rate).
   - However, graph-augmented tree models did not beat standalone GNNs or matched non-graph neural models.

4. **Honest Scientific Conclusion**:
   > *Learned GraphSAGE spatial embeddings do not add substantial predictive ranking power beyond original engineered tabular features when evaluated in a strict prospective-style framework. Engineered features—which explicitly include 12 spatiotemporal outbreak lags and host density metrics—already capture local transmission risk effectively.*
